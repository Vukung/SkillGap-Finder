# SkillGap Tracker

A powerful, single-page web application designed to help job seekers identify keyword gaps between a specific Job Description (JD) and their Resume. maximizing their chances of passing Applicant Tracking Systems (ATS).


## 🚀 Features

- **Smart Keyword Comparison**: Instantly matches your resume against a database of **200+ industry-standard keywords**, including:
  - Technical Hard Skills (Python, SQL, AWS, etc.)
  - High-Impact Action Verbs (Orchestrated, Spearheaded, etc.)
  - Soft Skills (Leadership, Adaptability, etc.)
- **Interactive Analysis**:
  - View **Match Score** percentage.
  - Interactive toggles to see exactly which keywords were found in the JD and which matched your resume.
  - Detailed list of **Missing Skills** to add.
- **Actionable Tips**: Generates dynamic advice based on your specific gaps.
- **Privacy First**: **100% Client-Side**. No data is sent to any server. All processing happens locally in your browser.
- **Brutalist Design**: A bold, high-contrast UI built with Tailwind CSS.

## 🛠️ How to Use

1. **Clone** or **Download** this repository.
2. Open the `index.html` file in any modern web browser.
3. Paste the **Job Description** in the left box.
4. Paste your **Resume** in the right box.
5. Click **ANALYZE**.
6. Review your Match Score and click the **Total Keywords** or **Matched** buttons to see deep insights.

## 🏗️ Tech Stack

- **HTML5**
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript** (ES6+)
